# CreditCard_Validation
This Python script checks if a credit card number is valid using the Luhn algorithm.
## How to Run
1. Run the script: `python creditcard_validation.py`
2. You will see 'VALID!' or 'INVALID!' depending on the card number.

## Example
Input: `4111-1111-4555-1142`  
Output: `VALID!`
